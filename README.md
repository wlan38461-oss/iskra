# Искра 🔥

Трекер ежедневных дел с питомцем. Каждое выполненное дело — полено для Искры,
маленького огненного духа. Закрыл все дела за день — серия растёт, а Искра
эволюционирует: Искорка → Огонёк (3 дня) → Пламя (7) → Феникс (14).
Пропустил день — серия сгорает, Искра тлеет.

- Kotlin + Jetpack Compose, процедурный пиксель-арт питомца
- Виджет на рабочий стол (Glance): питомец, серия, прогресс дня
- APK собирается GitHub Actions на каждый пуш в `main` и кладётся в ветку `builds`
