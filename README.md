# Искра 🔥

Трекер ежедневных дел с пиксельным питомцем-огоньком.

- **Яйцо → Огонёк → Пламя → Феникс.** Три дня, когда все дела сделаны, — и из яйца вылупляется Огонёк. Дальше он подрастает каждый засчитанный день.
- **Серия и угольки.** Дни подряд — серия; каждые 7 дней дают уголёк, который спасёт серию при пропуске.
- **Оформление по времени суток.** Рассвет, утро, день, закат, вечер и ночь — небо, солнце/луна и цвета интерфейса.
- **Напоминания.** Утренний план, вечернее напоминание, «последний шанс» и время для каждого дела с кнопками «Готово» и «Через 30 мин».
- **Виджеты.** Питомец 2×2, список дел 4×2 (отмечать прямо с рабочего стола) и полоса серии 4×1.

Kotlin + Jetpack Compose + Glance. Питомец и пейзаж рисуются процедурно (`pet/`, `scene/`).

## Сборка

Каждый пуш в `main` в GitHub Actions:
1. прогоняет юнит-тесты и собирает APK → ветка `builds`;
2. запускает эмулятор и снимает скриншоты всех экранов, вылупления, уведомлений и виджетов → ветка `shots`.
